HopGauge 1.0 Beta 2 brings the public repository and downloadable app into the same release.

> These are archived historical notes from before the current HopGauge package identity. The original release assets remain unchanged; use the latest release for current installation files.

## Included

- Network overview with Wi-Fi, gateway, DNS, Internet, VPN, proxy, and public egress status
- Per-process traffic, active connections, and listening ports
- Wi-Fi radio details, channel occupancy, interference guidance, and latency history
- Cloudflare download throughput test
- Website timing across DNS, TCP, TLS, first byte, and download phases
- Menu bar summary with a 30-second refresh interval
- English, Simplified Chinese, Japanese, and Korean interface languages

## Changes since Beta 1

- Adopted the 0BSD license across source code, tests, documentation, and bundled artwork
- Added English contribution, security, privacy, governance, architecture, support, and release documentation
- Added Apple Silicon CI, issue forms, a pull-request template, CODEOWNERS, and Dependabot
- Added repeatable versioned packaging with an embedded license and SHA-256 verification
- Removed obsolete compiled files and all current-tree references to the previous product name
- Fixed English self-test data and localized DNS verdict matching

## Verification

- 31 automated tests pass locally and in GitHub Actions.
- The app is a thin arm64 Mach-O bundle with an ad-hoc signature.
- The bundle contains the 0BSD license and reports release version `1.0.0-beta.2`.
- The separate `.sha256` asset verifies the downloadable zip.

## Requirements

- Apple silicon Mac
- macOS 14 Sonoma or later

## Install

This build is superseded. Install the latest HopGauge beta from GitHub Releases.

## Distribution note

This beta is ad-hoc signed and is not notarized by Apple. It does not include an auto-updater. The release supports arm64 only.
