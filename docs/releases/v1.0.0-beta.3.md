NetPulse 1.0 Beta 3 corrects the application icon distributed in Beta 2.

## What changed

- Replaced the opaque square canvas with a transparent rounded icon that sits cleanly on both light and dark backgrounds
- Preserved the existing Wi-Fi and pulse mark, color palette, lighting, and depth
- Corrected every generated iconset entry to use its required pixel dimensions on Retina displays
- Added an automated test for icon dimensions, alpha support, and transparent corners

## Verification

- All 32 automated tests pass locally and in GitHub Actions.
- The app icon was inspected from 16px through 1024px on light and dark backgrounds.
- The bundle is arm64-only, contains the 0BSD license, and reports release version `1.0.0-beta.3`.
- The separate `.sha256` asset verifies the downloadable zip.

## Requirements

- Apple silicon Mac
- macOS 14 Sonoma or later

## Install

1. Download `NetPulse-1.0.0-beta.3-macOS-arm64.zip` and its `.sha256` file.
2. Verify the download with `shasum -a 256 -c NetPulse-1.0.0-beta.3-macOS-arm64.zip.sha256`.
3. Extract the zip and move `NetPulse.app` to Applications.
4. On first launch, Control-click the app, choose **Open**, and confirm.

## Distribution note

This beta is ad-hoc signed and is not notarized by Apple. It does not include an auto-updater. The release supports arm64 only.
