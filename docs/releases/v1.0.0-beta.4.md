HopGauge 1.0 Beta 4 completes the menu bar experience and adds direct control over whether it is shown.

> These are archived historical notes from before the current HopGauge package identity. The original release assets remain unchanged; use the latest release for current installation files.

## What changed

- Added a native menu bar panel with signal strength, Wi-Fi link rate, current-channel congestion, gateway latency, DNS latency, and overall network health
- Added Open HopGauge, Refresh, and Quit actions to the panel
- Added a persistent menu bar visibility control to the gear menu in the main window and the standard Settings window
- Added a lightweight 30-second menu bar snapshot that refreshes immediately when the panel opens
- Added complete English, Simplified Chinese, Japanese, and Korean labels for the new interface
- Added deterministic menu bar and settings previews plus preference regression coverage

## Verification

- All 35 automated tests pass locally and in GitHub Actions.
- The menu bar and settings views were inspected in English and Simplified Chinese.
- Menu bar visibility defaults to enabled and persists after it is changed.
- The bundle is arm64-only, contains the 0BSD license, and reports release version `1.0.0-beta.4`.
- The separate `.sha256` asset verifies the downloadable zip.
