HopGauge 1.0 Beta 5 completes the product rename and makes live measurements easier to read.

## What changed

- Renamed the app, Swift package, executable, bundle identifier, build artifacts, repository, interface, and documentation to HopGauge
- Added a one-time migration for language, menu bar visibility, and recent diagnosis preferences from earlier beta builds
- Added hop-by-hop route tracing with bounded probes, silent-hop handling, destination status, and an active-VPN notice
- Rebuilt the download test around a native animated needle driven by rolling-window instantaneous speed
- Added a live throughput curve, running average, peak, stage, received data, and progress display
- Replaced the generic status item with a text-free HopGauge icon whose entire color follows network health while its pulse trace animates locally
- Added current-channel congestion to the menu bar panel
- Updated the project documentation, screenshots, tests, privacy notes, and release workflow for the new identity

## Verification

- The complete automated test suite passes locally and in GitHub Actions.
- The app, menu bar panel, speed test, settings, and deterministic screenshots were inspected after the rename.
- The release bundle is arm64-only, ad-hoc signed, and contains the MIT license.
- The separate `.sha256` asset verifies the downloadable zip.

## Requirements

- Apple silicon Mac
- macOS 14 Sonoma or later

## Install

1. Download `HopGauge-1.0.0-beta.5-macOS-arm64.zip` and its `.sha256` file.
2. Verify the download with `shasum -a 256 -c HopGauge-1.0.0-beta.5-macOS-arm64.zip.sha256`.
3. Extract the zip and move `HopGauge.app` to Applications.
4. On first launch, Control-click the app, choose **Open**, and confirm.

## Distribution note

This beta is ad-hoc signed and is not notarized by Apple. It does not include an auto-updater. The release supports arm64 only.
