# Support

HopGauge is maintained as an open-source beta. Support is handled through GitHub Issues.

## Ask a question or report a bug

Open an [issue](https://github.com/JasonGuoo/HopGauge/issues/new/choose) and include:

- What you expected and what happened
- The HopGauge version or commit
- The macOS version and Mac model
- Whether the Mac uses a VPN, proxy, private relay, or managed network
- Steps that reproduce the problem
- Relevant screenshots or logs after redaction

HopGauge supports Apple silicon and macOS 14 or later. Intel-only problems and older macOS versions are outside the supported configuration.

Never post a suspected vulnerability in a public issue. Follow [SECURITY.md](SECURITY.md) for private reporting.
