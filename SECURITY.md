# Security Policy

## Supported versions

Security fixes are applied to the current `main` branch and the latest published beta. Older beta builds may not receive fixes.

| Version | Supported |
| --- | --- |
| Latest beta | Yes |
| Older beta builds | No |

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's [private vulnerability report](https://github.com/JasonGuoo/HopGauge/security/advisories/new) instead.

Include the following when possible:

- A clear description of the issue and its impact
- The HopGauge version or commit
- The macOS version and Mac model
- Steps or a minimal proof of concept
- Whether the issue requires a particular network, permission, or user action

Remove real SSIDs, IP addresses, hostnames, account names, and unrelated process information. If a detail is essential to reproduction, call that out before sharing it.

The report will be reviewed privately. A fix and disclosure plan will be coordinated before public details are posted. Please do not test against systems or networks you do not own or have permission to use.
